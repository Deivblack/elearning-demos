# Avatar layer (reemplazable)

Coloca aquí la imagen del guía. El módulo carga por defecto:

- `guide.jpg` (o cambia el `src` en `index.html` / atributo `data-avatar-src`)

**Recomendado:** cuadrado 512×512 o 1024×1024, JPG/PNG/WebP.  
Para cambiar el avatar sin tocar lógica: sustituye `guide.jpg` por tu archivo con el mismo nombre.
